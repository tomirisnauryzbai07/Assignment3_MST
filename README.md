Assignment 3 – Minimum Spanning Tree (MST)

Student: Tomiris

Topic: Algorithms of Prim and Kruskal



Goal of the work:

The goal of this assignment is to write a program that finds the Minimum Spanning Tree (MST) of a given graph using two algorithms: Prim’s and Kruskal’s.
The program reads graph data from a input.json file, calculates MST with both algorithms, prints the results in the console, and writes them to output.json.

Project Structure:
src/main/java/com/tomi/algorithms/
│
├── Main.java             
├── Graph.java           
├── Edge.java             
├── PrimAlgorithm.java    
├── KruskalAlgorithm.java 
├── JsonHandler.java      
└── input.json

Result:

Both algorithms produce the same MST result.
The project successfully implements reading and writing JSON files, and demonstrates understanding of basic graph algorithms.

Conclusion:

This assignment helped me understand how minimum spanning trees work and how to implement them using different algorithms.
